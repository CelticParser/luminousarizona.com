# Markdown poem / sonnet highlighting

Highlights text between opening and closing `""` delimiters (same convention as the site’s `markdown-it-poem-sonnet` plugin) inside `.md` files.

## Install (Cursor or VS Code)

1. Command Palette: **Extensions: Install from Location…**
2. Choose this folder: `extensions/markdown-poem-sonnet` (the folder that contains `package.json`).

Reload the window if prompted.

## Colors

Workspace settings in `.vscode/settings.json` map `string.other.poem-sonnet.markdown` to an orange foreground. Adjust `editor.tokenColorCustomizations` there if you want a different shade.
